# AI Video Editor (Namma Kadhai)

Edits Tamil/Tanglish talking-head Reels: trims pauses, adds subtitles, B-roll, mood-based text and sound, then renders 1080x1920 for Instagram.

## Folders, in work order
| Folder | What goes there |
|---|---|
| `1_raw/` | Your camera footage |
| `2_broll/` | B-roll clips, AI illustrations, memes |
| `3_subtitles/` | Subtitle (SRT) files |
| `4_previews/` | Previews to review, and each Reel's speaker base |
| `5_exports/` | Finished videos, SRTs and covers, ready to post |
| `references/` | Reels used as style references |
| `engine/` | The editing engine and story scripts |
| `remotion/` | The graphics and text project |
| `stories/` | One folder per Reel: its settings and `beats.json` |
| `fonts/` | Fonts with their licences |

`STYLE.md` is the look and the rules; `PIPELINE.md` lists the commands in order. Footage, previews, exports and subtitles stay on your computer and are never pushed to GitHub.
